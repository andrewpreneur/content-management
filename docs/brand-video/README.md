# SaaSSuite video brand style — work in progress

Goal (Andrew, Nov 8): one cohesive, memorable editing style for SaaSSuite across speaker videos, no-speaker motion graphics, ads and carousels.

1. **Library:** 64 reference videos broken down in `library/<id>.json` (schema in `SCHEMA.md`). Source mp4s live on the work machine at `/home/user/work/refs/`, re-downloadable from the URLs in Andrew's Nov 8 message.
2. **Filter:** 35 videos scored 4–5 for SaaSSuite fit; their 120 best 5-second moments are in the Style Picker.
3. **Pick:** Style Picker https://claude.ai/artifact/3yd8WumqNUQugNH1Y7GSo3. A vs B, then what was liked. Picks are stored in the page database, collection `picks` (`{a, b, winner, liked[], disliked[], note, at}`). Build tool: `tools/style_clips.py`.
4. **Next:** turn picks into 3–5 named styles by use case (no-speaker launch, speaker + captions, carousels/statics), with "more" and "simpler" dials. Recreate the winning moves and write a skill.
